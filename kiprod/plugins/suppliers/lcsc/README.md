# LCSC supplier profile

- Category: Component distributor
- Official site: https://www.lcsc.com/
- Integration status: read-only partner keyword search; it requires credentials issued by LCSC after partner application and approval.
- Search uses LCSC's documented exact-MPN mode and returns matching product pricing and stock when present. It does not access cart, order, or account APIs.
- LCSC documents a maximum of 30 search results per page and permits USD, CNY, EUR, and HKD currency selections.
- Apply for API access through LCSC's official [API program](https://www.lcsc.com/agent/) and review the current API terms before use. Store the API key and secret in the OS keyring through supplier settings.
- Verify current pricing, stock, lead time, and terms directly with LCSC.
