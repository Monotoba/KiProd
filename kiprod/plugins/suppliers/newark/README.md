# Newark supplier profile

- Category: Component distributor
- Official site: https://www.newark.com/
- Integration status: read-only Product Search API adapter; requires an API key issued by the element14 Partner Portal.
- Offers can be reviewed from supplier quote files imported through KiProd’s RFQ workflow.
- Verify current pricing, stock, lead time, process capabilities, and terms directly with the supplier.
- Listed-name aliases: NEWARK.
- Search uses the documented manufacturer part number query and returns generic catalog price breaks and stock where available. It does not request contract pricing, create carts, or submit orders.
- The store and currency must match the Newark regional catalog selected in supplier settings.
- Register for an API key through the official [element14 Partner Portal](https://partner.element14.com/) and review [Newark's API terms](https://www.newark.com/services/purchasing-procurement-support/search-api) before use.
- Store the API key in the OS keyring through supplier settings.
